# SA2DGE — Stage 1 Documentation

**File:** `SA2DGE_Stage1_Documentation.docx` (10 pages)
**Author:** Shreyas Pathak

## What it is
The official Stage 1 project document for **SA2DGE** (Shreyas's Advance 2 Dimensional Game Engine), a proprietary 2D game engine built in C# / .NET with Vortice and Direct3D 11 on Windows.

## What it's for
- A formal project record of Stage 1 (architecture, core runtime, first working graphics output).
- A learning reference for the game-engine concepts behind the project.
- A base document for reviews, evaluations and later stages.

## What's inside
- **Part A (pp. 3–6):** game development and engine fundamentals — game loop, delta time, fixed timestep, platform layer, Direct3D 11, DXGI, swap chain, architecture principles.
- **Part B (pp. 7–10):** SA2DGE overview, subsystem architecture, Core classes, the verified rendering pipeline (red frame on screen), Phase 2 roadmap and conclusion.
